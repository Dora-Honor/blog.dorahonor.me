## 前言

最近使用 Windows 更新安装各种补丁更新，顺便安装了驱动更新。绝大部分都没啥问题。

但是在安装好 Byosoft BIOS 固件更新后就出了问题，重启显示 logo 一段时间后，就出现了蓝色提示框，说是安全启动验证失败导致无法启动。

在该界面，如果你按任意键都会进入 EFI Shell 界面；而在该界面，即便你通过 OTG 连接了有线键盘，也无法输入命令。此时你只能按住电源键 10 秒以上强制重启。

## 解决方案

遇到这种情况，并非没有解决方案。

### 暂时关闭安全启动

通过 OTG 连接你的键盘，启动或重启平板，在出现 logo 前狂按 F2 进入 BIOS 设置。

![](https://img.dorahonor.me/2026/10/20/182042_1792487683129.webp)

进入 `Device Manager` - `System Setup` - `Boot`，将 `Secure Boot` 项改为 `Disable`。

![](https://img.dorahonor.me/2026/10/20/182042_1792487683160.webp)

![](https://img.dorahonor.me/2026/10/20/182042_1792487683179.webp)

![](https://img.dorahonor.me/2026/10/20/182042_1792487683246.webp)

![](https://img.dorahonor.me/2026/10/20/182042_1792487683234.webp)

按 F10 保存设置，回到主界面，导航到 `Continue` 项进入。此时会出现蓝底白字的已更改设置提示，按回车即可。

![](https://img.dorahonor.me/2026/10/20/182042_1792487683216.webp)

![](https://img.dorahonor.me/2026/10/20/182042_1792487683198.webp)

### 解密设备

Windows 启动时，会提示你解锁 BitLocker。

> [!note]
> 解锁时并未拍照，因此无图。

在解锁界面，正确输入解锁密钥。在登录了 Microsoft 账户的情况下，解锁密钥可以在该 Microsoft 账户里找到，在此不再阐述。

输入完成后，系统会自动重启。

> [!caution]
> 如果你设置了 PIN，有可能暂时无法使用，此时你需要用 Microsoft 账户密码进行登录。

进入桌面后，按 `Win` + `i` 进入 Windows 设置，选择【更新和安全】项。

![](https://img.dorahonor.me/2026/10/20/182042_2026-10-20_175737.webp)

在左侧找到并单击进入【设备加密】项，单击【关闭】进行解密，注意解密需要一段时间。（我这是已经解密的）

![](https://img.dorahonor.me/2026/10/20/182042_2026-10-20_020651.webp)

### 恢复安全启动，（可选）重新加密

解密完成后，重启平板，按照 [暂时关闭安全启动](#暂时关闭安全启动) 这一步进入 BIOS 设置项，将 `Secure Boot` 项改回 `Enable` 保存即可。

此时，重启不会再报错了，哪怕重新加密也不会。

如需加密，可在 [解密设备](#解密设备) 这步最后部分，单击【打开】重新加密。
